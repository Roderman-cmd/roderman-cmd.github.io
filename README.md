# roderman-cmd.github.io

Web pages for Roderman's apps, published with GitHub Pages.

- `fittracker/`: FitTracker's home page, `fittracker/support/` and `fittracker/privacy/`. The app's Settings and its App Store Connect listing link to these. The source is the `Website/` folder in the FitTracker repository; change them there and copy them here.

`.nojekyll` makes GitHub Pages serve the files as they are.
